# 角色模型

三个职业各一个 GLB，文件名固定，改模型直接覆盖同名文件即可。

| 文件 | 职业 | 武器 |
|---|---|---|
| `warrior.glb` | 战士 · 刀客 | 刀 |
| `mage.glb` | 法师 · 术士 | 法杖 |
| `taoist.glb` | 道士 · 符师 | 符剑 / 桃木剑 |

## 模型要求

- **格式**：glTF 二进制 `.glb`（单文件，贴图内嵌）
- **必须带骨骼蒙皮**（SkinnedMesh + Bone）。静态模型动不了，只能用第一帧当雕像
- **至少 3 个动画 clip**，名字里带上关键词就能自动识别：
  - `idle` — 待机
  - `walk` 或 `run` — 移动
  - `attack` — 攻击（`slash` / `punch` 也认）
  - `die` — 死亡（可选，不提供就直接倒下）
- **朝向**：按 glTF 惯例 **+Z 朝前**。如果你的模型是 -Z 朝前，在 `src/skel.js` 注册表里加 `{ yaw: Math.PI }`
- **尺寸不用管**：加载时会自动量包围盒、按身高归一化到 1.9，并让脚底对齐 y=0。想让角色更高，注册时加 `{ height: 2.05 }`

## 骨骼命名

`src/skel.js` 里的 `SKEL_BONES` 会自动匹配 Mixamo（`mixamorig:LeftArm`）和
MetaHuman（`upperarm_l`）两套命名。用别的命名也能跑，只要骨骼名里包含
`head` / `spine` / `leftarm` / `rightupleg` 这类关键词就行；
实在认不出就改 `SKEL_BONES` 里的别名表。

## 装备怎么处理

盒子版纸娃娃的护甲是**用代码现码几何体**（`applyPaperDoll()` 里 `boxGeo` 拼肩甲、头盔、披风），
贴到写实模型上会很怪。所以骨骼版只保留：

- 无贴图的材质按职业染色、按装备品质发光
- 武器 / 副手挂到左右手骨骼
- 套装光环

护甲外观要等有正式模型后，改成「按部位换 mesh」或直接换贴图。
