# Boss 技能组设计 · 从「换个颜色」到「换一套规则」

> 状态：**机制层已进特效台**（`docs/boss-vfx-playground.html`），游戏侧未接入
> 提出：2026-10-29 ｜ 分支 `feat/skill-refactor`
> 前置：`docs/BOSS-VFX-PLAN.md`（表现层盘点）—— 那份解决「只有一个圈」，
> 这份解决「每只 Boss 打起来一样」。

---

## 0. 一句话

旧结构是 **13 种共享技撑 39 个技能位**，其中 `slam` / `ringshot` / `charge`
各被 6 只 Boss 共用、`summon` 被 8 只共用。**换 Boss 只是换颜色**，
因为技能根本没有"属于这只 Boss"的部分。

新结构：**每只 Boss 4 个位 = 1 个专属机制 + 2 个套路技 + 1 个专属签名**。
专属机制负责回答"这只 Boss 逼我做什么动作"，签名负责"这一战的气氛"。

---

## 1. 暗黑 2 的 Boss 到底靠什么制造挑战

不是伤害数字，是**限制玩家的行动**。拆开看只有五条：

| 原则 | 暗黑 2 的例子 | 玩家被迫做的事 |
|---|---|---|
| **场地被切割** | 暗黑（Diablo）的火墙、墨菲斯托的环形弹幕 | 只能从缺口走，站位变成决策 |
| **持续区域累积** | 安达利尔的毒新星、尼拉塞克的毒云 | 不能站桩，必须一直挪 |
| **限时目标** | 尼拉塞克的尸爆（先清尸体）、巴尔的分身 | 优先级判断：先打谁 |
| **定向威胁** | 都瑞尔的冲锋（直线、有前摇） | 侧闪/绕背，而不是后退 |
| **读条与打断** | 巴尔的冰冻波、女伯爵的火墙 | 打断 or 躲远，二选一 |

反面教材正是我们现在的状态：**全部是"以 Boss 为圆心的圆"** ——
玩家的唯一反应是"往外跑"，跑出去就安全，于是所有 Boss 同一种解法。

> 判据：如果一个技能的解法是"离开圆心"，那它和别的技能没有区别。
> 新机制必须各自对应**不同的动作**：绕背、离开扇面、拉开距离、走进圈内、
> 打掉目标、背对、抢时间。

## 3. 共用的是"原语"，不是"技能"

上一版的问题是把**技能**共享了；正确做法是共享**原语**：

| 原语 | 用途 | 谁在用 |
|---|---|---|
| `BFX.zone({shape})` | circle / ring / rect / sector 四种预警 | 全部（形状跟着判定走） |
| `BFX.column` | 竖柱（火柱/传送门/光柱） | 火墙、召唤、冰封、摆渡 |
| `BFX.spikes` | 地刺/藤蔓/冰棱 | 藤蔓、千里冰封、卵囊 |
| `BFX.boulder` | 落石（可带火拖尾） | 落石、陨石、岩枪 |
| `BFX.blade` | 剑影（剑尖朝下） | 剑雨、剑域、万剑归宗 |
| `BFX.wave` | 立起来的冲击墙 | 砸地、地震、火墙、潮 |
| `BFX.ribbon` | 有宽度的丝/链 | 噬血链、魂锁、石化视线 |
| `BFX.decal` | 焦痕/裂纹/霜纹/毒斑/蛛网/法阵 | 全部 |
| `floatText` + 判定圈 | **把判定形状画出来** | 全部（验收工具） |

**判定与预警必须同源**：`skill.hit()` 返回的数字，既用来画预警，也用来判命中。
特效台里"显示判定形状"就是把这份数字画成红线——对不上就是 bug。

## 4. 还需要游戏侧支持的四件事

特效台只是"看得见"，要真的成立还得改 `src/game.js`：

1. **状态位**：定身（石化/冰封）、拉拽（魂锁）、位移（摆渡/冲撞）——
   现在玩家只有减速，没有"不可控位移"和"定身"。
2. **可破坏目标**：图腾、卵囊需要有血量与仇恨（现在 `enemies` 里只有怪）。
3. **减伤朝向**：`stonearmor` 需要"从正面来的伤害 ×0.2"的判定，
   即伤害来源与 Boss 朝向的点积。
4. **限时/读条**：卵囊 6 秒、图腾 5 秒，需要挂在 Boss 状态机上的定时器，
   而不是 `setTimeout`（切图会漏）。

## 5. 落地顺序

| 批 | 内容 | 为什么先做 |
|---|---|---|
| **A** | `zone` 四形状 + 判定同源 | 一个改动同时修掉「全是圆」和「形状≠判定」 |
| **B** | 12 个专属机制（本文 §2 第 1 位） | 这是"换 Boss 有新鲜感"的全部来源 |
| **C** | 状态位（定身/拉拽/位移） | B 里有 5 个机制依赖它 |
| **D** | 12 个签名 + 13 个套路技重做 | 表现升级，判定不变 |

> 顺序不能倒：先做 D 会得到一堆好看但仍然同质的技能。

## 6. 验收

- **一句话测试**：任取一个机制技，遮住血条后玩家能不能说出"我该做什么"。
- **同质化测试**：12 只 Boss 的机制技两两比较，**解法动词**不得重复
  （绕背 / 离开扇面 / 拉距离 / 打目标 / 抢时间 / 反向跑 / 认核 / 走出去）。
- **判定一致**：开「显示判定形状」，红线必须与预警的边界重合。
