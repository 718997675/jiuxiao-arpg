## 1. 暗黑 2 的 Boss 到底靠什么制造挑战

不是伤害数字，是**限制玩家的行动**。拆开看只有五条：

| 原则 | 暗黑 2 的例子 | 玩家被迫做的事 |
|---|---|---|
| **场地被切割** | 暗黑（Diablo）的火墙、墨菲斯托的环形弹幕 | 只能从缺口走，站位变成决策 |
| **持续区域累积** | 安达利尔的毒新星、尼拉塞克的毒云 | 不能站桩，必须一直挪 |
| **限时目标** | 尼拉塞克的尸爆（先清尸体）、巴尔的分身 | 优先级判断：先打谁 |
| **定向威胁** | 都瑞尔的冲锋（直线、有前摇） | 侧闪/绕背，而不是后退 |
| **读条与打断** | 巴尔的冰冻波、女伯爵的火墙 | 打断 or 躲远，二选一 |

反面教材正是我们现在的状态：**全部是"以 Boss 为圆心的圆"** ——
玩家的唯一反应是"往外跑"，跑出去就安全，于是所有 Boss 同一种解法。

> 判据：如果一个技能的解法是"离开圆心"，那它和别的技能没有区别。
> 新机制必须各自对应**不同的动作**：绕背、离开扇面、拉开距离、走进圈内、
> 打掉目标、背对、抢时间、认核。

## 2-B. 6 只世界 Boss（四格全独占）

数据照 `origin/feat/act-expansion` 的 `src/data/data-worldboss.js`，
模型照 `src/wbmodels.js` 移植（**真实米数建模**，进台时按 `wbScale` 缩小）。
共同设计语言：

- **没有 `patterns`** —— 那是八部天龙的语言（共用池）。世界 Boss 每只三招独占。
- **没有元素缺口** —— 抗性五项同值。八部考「换武器」，这里考「换站位 / 读阶段」。
- **领域是唯一识别符号** —— 进场就有一条持续规则在改玩家，不是一段技能动画。
- **三阶段按血量比例** 1.00 / 0.66 / 0.33，每段换一套招 + 改一条规则。

## 3. 共用的是"原语"，不是"技能"

上一版的问题是把**技能**共享了；正确做法是共享**原语**：

| 原语 | 用途 | 谁在用 |
|---|---|---|
| `BFX.zone({shape})` | circle / ring / rect(线) / sector(扇形) / scatter(多点) 五种预警 | 全部（形状跟着判定走） |
| `BFX.column` | 竖柱（火柱/水柱/光柱） | 龙息、水炮、狐火、火墙 |
| `BFX.spikes` | 地刺/藤蔓/冰棱/尾刺 | 藤蔓、千里冰封、尾缚、卵囊 |
| `BFX.boulder` | 落石（可带火拖尾） | 落石、陨石、反刍的腐骨 |
| `BFX.blade` | 剑影（剑尖朝下） | 剑雨、剑域、万剑归宗 |
| `BFX.wave` | 立起来的冲击墙 | 砸地、震地、九首齐啸、暗潮、战吼 |
| `BFX.arcSlash` | 立起来的弧刃（横斩） | 尾扫、风刃、斧劈、幻影突袭 |
| `BFX.ribbon` | 有宽度的丝/链 | 噬血链、魂锁、石化视线 |
| `BFX.decal` | 焦痕/裂纹/霜纹/毒斑/蛛网/法阵 | 全部 |
| `WBDOM` | 领域：常驻边界 + 每种一条自己的"活物" | 6 只世界 Boss |
| `NSYN`（8 个） | 本命技的动作语法：喷 / 扫 / 砸 / 追 / 围 / 标记 / 回响 / 改地 | 45 只守卫的第 5 格（§7） |
| `nField` | 一块"被改写过"的地：硬边 + 淡面（只靠 `decal` 画不出边界） | 改地类 |
| `nFollow` | 跟着玩家走的记号，六种形状 | 标记类 |

**判定与预警必须同源**：`skill.hit()` 返回的数字，既用来画预警，也用来判命中。
特效台里"显示判定形状"就是把这份数字画成红线——对不上就是 bug。

## 4. 还需要游戏侧支持的五件事

特效台只是"看得见"，要真的成立还得改 `src/game.js`：

1. **状态位**：定身（石化/冰封/尾缚）、拉拽（魂锁/吞咽）、位移（摆渡/冲撞/潜渊）——
   现在玩家只有减速，没有"不可控位移"和"定身"。
2. **可破坏目标**：图腾、卵囊需要有血量与仇恨（现在 `enemies` 里只有怪）。
3. **减伤朝向**：`stonearmor` / 刑天的盾需要"从正面来的伤害 ×0.2"的判定，
   即伤害来源与 Boss 朝向的点积。
4. **限时/读条**：卵囊 6 秒、图腾 5 秒、九首齐啸 3 秒，需要挂在 Boss 状态机上的
   定时器，而不是 `setTimeout`（切图会漏）。
5. **领域**：一条**每帧都生效**的规则（视野 / 移速 / 持续掉血 / 吸力 / 攻速 /
   小地图）。它不进伤害管线，走的是 `updatePlayer` 里的乘区。

## 5. 落地顺序

| 批 | 内容 | 为什么这个顺序 |
|---|---|---|
| **A** | `zone` 五形状 + 判定同源 | 一个改动同时修掉「全是圆」和「形状≠判定」 |
| **B** | 18 个专属机制（§2 第 1 格） | 这是"换 Boss 有新鲜感"的全部来源 |
| **C** | 状态位（定身/拉拽/位移） | B 里有 5 个机制依赖它 |
| **D** | 6 只世界 Boss（领域 + 三阶段 + 18 招） | 依赖 C 的位移与状态位，也必须最后做 |
| **E** | 45 只的**本命技**（§7），每只独占第 5 格 | ✅ 已做完 —— 51 只没有两只同套 |

## 6. 验收

- **一句话测试**：任取一个机制技，遮住血条后玩家能不能说出"我该做什么"。
- **同质化测试**：两两比较，**解法动词**不得重复
  （绕背 / 离开扇面 / 拉距离 / 打目标 / 抢时间 / 反向跑 / 认核 / 走出去）。
- **判定一致**：开「显示判定形状」，红线必须与预警的边界重合。
- **技能组不重复**：51 只里**不许出现两只技能组完全相同**。现在是 5 格
  （世界 Boss 4 格），**0 对重复**；前四格还剩 7 对重复，全被第 5 格拆开了。

## 7. 45 只的本命技（已完成）

把前四格按 id 统计一遍，原来是这样：

| | 种类数 | 最大共用 |
|---|---|---|
| 机制位 | 18 | `staggerbreak` 被 **8 只**用；`mirror` 5 只；`bladedomain` 4 只 |
| 签名位 | 12 | `stonespear` 被 **7 只**用；`soulchain` 6 只；`bladering` 6 只 |

**12 只 Boss 的四格与另一只完全相同**（赤炎魔将 = 焚天炎帝、天罡剑魂 = 剑冢守灵、
髓主 = 南天守门神、混沌真身 = 无相天魔 ……）。那不是"相似"，是同一套配置贴了两个名字。

做法：给每只加**第 5 格 = 本命技**，只属于它自己。前四格不动 ——
那四格说明"它像谁"，第 5 格说明"它是谁"。挂上去之后 `KIT` 变成：机制 / 套路 ×2 /
签名 / **本命**，51 只里没有任何两只是同一套。

### 7.1 共用的不是技能，是动作语法

45 只不可能有 45 个全新的动词 —— 但可以有 8 个语法 × 6 种排布 × 5 种时序。
**两只允许用同一个语法，但必须同时在排布与时序上不同**；三元组
`(语法, 排布, 时序)` 在表里**互不相同**（45 个，查重通过）。

| 语法 | 动作 | 玩家被迫做的事 | 只数 |
|---|---|---|---|
| **喷** `spray` | 多口朝外射，中间留缝 | 找缝，侧身半步 | 5 |
| **扫** `sweep` | 一道刀/墙绕着身扫过 | 跟着弧尾跑，或从背后穿 | 7 |
| **砸** `drop` | 落点先摆好，再依次/同时砸 | 记先后，踩缝 | 9 |
| **追** `seek` | 一颗一颗锁你**当时**的位置 | 一直移动，别停 | 5 |
| **围** `cage` | 一圈柱子围住你，留一个缺口 | 冲出去（不是绕） | 5 |
| **标记** `mark` | 记号**跟着你走**，落地才炸 | 最后一刻横移 + 带离人群 | 6 |
| **回响** `echo` | 打你**刚才站过**的位置 | 换方向，别直线往返 | 2 |
| **改地** `rewrite` | 不改你，改地面：站上去就掉血 | 记住哪块地还在 | 6 |

> 「追」和「回响」最容易混：追打的是**现在**（跑就对），回响打的是**过去**
> （跑还不够，得换方向，否则一串脚印正好连成你折返的路线）。

| 排布 | 场地类（砸/改地）的含义 | 轨迹类（追/标记/回响）的含义 |
|---|---|---|
| `line` 一字 | 一条横线压过来 | 不加宽，只留一串 |
| `arc` 弧 | 沿弧铺开 | 左右交替 |
| `spiral` 螺旋 | 由内向外旋 | 正弦摆动 |
| `grid` 棋盘 | 网格占格 | 两倍加宽 |
| `side` 单侧 | 全贴一侧，只留走廊 | 全堵你顺手那边 |
| `cross` 十字 | 十字交错 | ±两次交替 |

| 时序 | 含义 |
|---|---|
| `all` 同时 | 一起落 —— 只有缝是安全的 |
| `seq` 依次 | 按排布顺序落 —— 记顺序 |
| `rev` **反向** | 倒着落 —— 先看最后那一下 |
| `delay` 延迟爆发 | 先全场亮起，等一拍再一起落 —— 有整整一秒可以走 |
| `wave` 隔拍两波 | 一波一波，中间换缺口 |

### 7.3 怎么验的

- `NATIVE` 45 键 ↔ 45 只非世界 Boss，**一一对应，0 缺失**；每只 `KIT` 末位就是
  `nt_<它自己的 id>`。
- 三元组 `(语法, 排布, 时序)` **45 个互不相同**；45 个技能名也互不相同。
- 全量施放：**51 只 × 全部技能 = 249 次，0 报错**，页面 0 异常。
- 技能组从 4 格变 5 格，**51 只里没有两只五格完全相同**（前四格仍有 7 对重复，
  但第 5 格把每一对拆开了）。

### 7.4 特效台里踩的四个坑（都已修）

1. **围栏围着 Boss 摆 = 根本没围住人。** 第一版 `cage` 以 Boss 为心、半径 13 米
   摆 7 根柱，俯视角下只是一圈稀疏的刺，缺口也读不出来。改：**围着玩家**，
   半径由柱子数量反推 —— 柱子的判定圆直径必须略小于弧长（`D×2π/k`），一圈才连得起来。
2. **落点围着 Boss 摆，标题却写"锁在你身上"。** 第一版 `seek` 把 12 个落点沿弧
   摆在 Boss 前方十几米，红圈根本不在玩家脚下，文案和行为自相矛盾。
   改：追 / 标记 / 回响全部**跟着玩家**，排布只决定这一串落点往两边散多宽。
3. **间距不跟半径走 = 铺满整屏。** `drop` 12 块落点用固定间距 3.6 米配半径 2.4，
   石块互相压住，整屏都是圈。改：间距 = `max(表里的 step, 半径 × 2.15)`。
4. **扫的覆盖面加了不该加的余量。** 单道 207° 的弧被画成 279°，玩家会以为背后
   也不安全 —— **假安全区比不画更坏**。改：`k=1` 时余量为 0。

### 7.5 还剩什么

- **游戏侧一件都没接**：§4 那五件事（状态位 / 可破坏目标 / 减伤朝向 / 挂在状态机
  上的定时器 / 领域乘区）现在都还只在特效台里演。
- `src/fx2.js` 没建：`BFX`、`NSYN`、`WBDOM` 全部挤在 `docs/boss-vfx-playground.html`
  里，搬进 `src/` 要剥掉舞台相关的那一半。
- **移动中的判定表达不了**：现在只有 circle/ring/fan/line/scatter/self 六种静态形状。
  "扫到一半停下""墙慢慢推过来"这类只能把**整段会挨到的范围**一次画出来，
  玩家看到的是"总共会挨到哪"，不是"此刻挨到哪"。这条要等 `zone` 支持带时间的
  扫掠形状才谈得上。
