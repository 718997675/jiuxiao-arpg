M1

装备系统 2.0

必做
基底 70→210　词缀 24→64
  • 槽位 11 → 14（披风 / 护符 / 命格）
  • 基底 8 阶，引入 ilvl 物品等级缩放数值
  • 新增元素伤害、+N 技能等级、光环、濒死免疫
  • 洗练台：重 roll 单条词缀 / 升品阶
  • 符文之语：24 符文 + 12 组合（艾尔+索尔+塔尔 → 连锁闪电）
  • 套装 5 → 12（每职业 3 + 通用 3），效果改为改机制
M2

怪物体系 2.0

建议
怪物 12→40　Boss 12→20
  • 10 个新程序化模型 + 元素变体
  • 精英词缀 12 种（冰霜 / 闪电 / 分裂 / 亡语…）
  • 族群抗性：亡灵抗毒、石魔抗物理、妖灵抗法术
  • 图鉴系统 + 区域集齐永久加成
  • AI 升级：包夹 / 风筝 / 自爆 / 治疗友军
  • 世界 Boss + 血月天气事件
M3

技能体系 2.0

必做
主动 18→36　变体 0→108　图标 0→36
  • 三职业各 12 技能，分三系（狂战 / 守护 / 破军…）
  • 技能等级 1–10，吃「+N 技能等级」词缀
  • 每技能 3 个符文改造：改机制不改名
  • 36 个技能图标，按 8 种施法形态归类；变体只叠 Ⅰ/Ⅱ/Ⅲ 角标
  • 技能栏 6 → 8（PC 1-8 / 手机 4×2）
M4

被动 / 天赋树

必做
节点 0→120　天赋点 0→70　图标 0→42
  • 每职业 3 系 × 10 节点 + 通用 30
  • 小节点 / 中节点（改机制）/ 大节点（质变）
  • 装备 flag 可激活隐藏节点，形成双构筑
  • 图标分层：90 个小节点共用 12 个属性符号，24 中节点独立，6 大节点插画级
  • 3 套预设一键切换 + 洗点金币递增
  • UI 用 Canvas 绘制连线（120 节点不卡）
M5

坐骑体系

建议
坐骑 0→6　培养 无→等级 / 亲密
  • 马 / 狼 / 鹿 / 鹤 / 虎 / 麒麟（终局）
  • Boss 掉落、任务、野外驯服
  • 骑乘战斗：攻速 −25%、移速 +45%
  • 受击 3 次落马 + 3 秒硬直
  • 3 个坐骑装备位（马鞍 / 蹄铁 / 铃铛）
M6

储物箱

建议
仓库 0→60+　背包 40→60
  • 账号仓库跨角色共享 + 材料独立仓
  • 分类标签 + 搜索 + 虚拟滚动
  • 套装收藏柜（登记后随时取出）
  • 一键整理：部位 → 稀有度 → ilvl
M7

建档 / 读档

必做
存档位 1→3　导入导出 无→有
  • schema v2 + 迁移器（V1 老档不丢）
  • JSON 导出 / 导入，带数值合法性校验
  • 原子写入（tmp → 替换），防写坏
  • 回档点 + 死亡惩罚二选一
M8

账号体系

可延后
登录 无→邮箱 / 手机　同步 无→云
  • 纯静态部署没有数据库，须用托管云服务
  • 本地优先，登录才开同步，不强制在线
  • 冲突弹窗让玩家选，不自动覆盖
  • 降级方案：JSON 导出即可跨设备搬档
M9

世界观 / 剧情

可延后
文本 3千→4万字　结局 1→3
  • 5 章主线：桃源烬 → 幽篁血竹 → 黄泉渡口 → 昆仑雪狱 → 九霄之上
  • 演出系统：镜头关键帧 + 打字机 + 音效点
  • 分支影响 NPC 存亡，结局三选一
  • 内置「山海志」图鉴 + 名词表 + 时间线
M10

体验感打磨

建议
贯穿全程　不单独占工期
  • 打击感：血雾 / 地面残留 / 破防硬直
  • BGM 三层（探索 / 战斗 / Boss）交叉淡入
  • 装备对比、伤害统计、拾取过滤
  • 手柄支持、色盲模式、字体缩放
  • 性能：对象池 + 粒子上限 + 小地图降帧
M11

图标视觉系统

必做
图标 17→105　独立绘制 105　外部请求 0
  • 统一 32×32 剪影 + currentColor，颜色全部交给 CSS（稀有度 / 系别 / 元素）
  • 配额：技能 36 / 天赋 42 / 符文 10 / 坐骑 6 / 材料 8 / 新槽 3
  • 变体、小节点、符文靠角标与组合压缩，200 个视觉只画 105 张
  • 天赋树走 Canvas：Path2D 启动时编译一次，120 节点稳 60fps
  • 每画 12 个拼一张对照墙，防画风漂移
  • 深色底 / 浅色底都要能看清，靠 currentColor 换色即可

依赖关系 顺序不能颠倒

S0 存档 v2 ──┬─→ S1/S2 装备（ilvl / 孔 / 符文 字段） ├─→ S3 天赋（talents 字段） ├─→ S6 仓库（stash 字段） ├─→ S7 坐骑（mount 字段） └─→ S9 账号（复用 SaveManager 序列化） S4 技能 ──→ S3 天赋（天赋节点要引用技能 id） S5 怪物 ──→ S1 掉落（掉落表按怪物等级生成） M11 图标规范 ──→ S3（42）+ S4（36）+ S2（10）+ S10（17） 规范与 Path2D 缓存必须最先定，否则天赋树画完要回头返工

砍单顺序 时间不够就按这个顺序放弃

优先级包含说明
1 · 必做 S0 存档 → S1 装备 → S3 天赋 → S4 技能 这四项完成，构筑深度就有了，玩家会想玩第二遍。含图标约 10 晚。
2 · 强烈建议 S5 怪物 → S6 储物箱 决定「刷得爽不爽」。约 5 晚，加上必做共 15 晚（两周半）。
3 · 可延后 S2 符文之语 · S7 坐骑 爽点但非核心，可放到 V2.1。
4 · 最后做 S8 剧情 4 万字 · S9 账号 工作量最大、最容易拖；账号只有多设备需求才必要。

主要风险

风险影响应对
存档迁移丢档玩家进度全失，致命迁移前自动备份 jiuxiao_save_v1.bak；迁移后校验和比对关键字段
数值失控后期无难度或前中期劝退每 Sprint 跑 1000 次战斗模拟：普通胜率 75% / 精英 55% / Boss 35%
内容量爆炸工期翻倍全部数据化 + AI 批量生成，人工只做审校；每 Sprint 设内容上限，超出就砍
账号需云服务部署形态变化，可能卡住先做 JSON 导出/导入兜底；账号作为可选增强，不阻塞发布
单一 data.js 破 3000 行改一处崩三处S0 阶段完成 src/data/ 拆分
手机端承载不了天赋树/仓库移动端体验崩天赋树用 Canvas + 双指缩放；仓库虚拟滚动；单独跑竖屏回归
图标画不完（105 个）拖住 S3/S4，或用占位符毁掉观感先定规范再画；变体/小节点/符文用角标与组合压缩；优先保 36 个技能图标，天赋图标可降级为圆点+数字
图标风格漂移界面显得杂统一 32×32 网格与 2px 安全边距；每画 12 个拼对照墙自查
铁律：每个 Sprint 结束都必须是「可玩、可发布」的状态，绝不留半截功能过夜。收尾必跑三端回归 + 存档往返 + 40 怪帧率。
