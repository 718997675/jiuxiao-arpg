## 一句话现状

旧的病是「换 Boss 只是换颜色」：13 种共享技撑 39 个技能位。现在三步走完了前两步 ——
**机制各自不同**（§7.2 判据：这一招逼玩家做的动作，和别的 44 只都不一样）、
**演出各自是"活物"**（留在场上、自己会动，不是画一下就没）。
第三步（进游戏）一步都没开始：定身 / 拉拽 / 可破坏目标 / 减伤朝向 / 领域乘区
这些**玩家侧状态**现在只存在于特效台。

## 下一步（按顺序，别跳）

1. **`src/fx2.js`**：把 `BFX`（含 5 个活物原语）、`NR`、`WBDOM` 从
   `docs/boss-vfx-playground.html` 搬到 `src/`，`index.html` 按序引入。
   搬的时候**只搬原语 + 数据表，不搬舞台**（`setBoss` / 假人 / 相机是特效台的东西）。
2. **玩家侧状态位**（§4.1）：定身 / 拉拽 / 不可控位移。现在玩家只有减速 ——
   石化、冰封、尾缚、魂锁、吞咽、摆渡全都在等这一条。落点建议 `updatePlayer` 里加
   `player.ctl = { root, pull, tp }`，由 `game.js` 每帧消费，和现有 `slow` 并列。
3. **可破坏目标**（§4.2）：图腾 / 卵囊 / 经幡 / 兽鼓要有血量与仇恨。
   最小做法：复用 `enemies`，加 `enemy.destructible = { hp, timer, onExpire }`，
   **优先打它**（点击选中 + 自动锁定优先级）靠 `nearestAggroEnemy` 那条口子扩。
4. **减伤朝向**（§4.3）：石甲 / 刑天盾 —— 伤害来源与 Boss 朝向的点积。
   入口是 `damagePlayer`，别在各技能 case 里加。
5. **定时器挂在状态机上**（§4.4）：卵囊 6 秒、图腾 5 秒、九首齐啸 3 秒。
   `setTimeout` 切图会漏，一律记在 boss 状态里按帧递减。
6. **领域乘区**（§4.5）：视野 / 移速 / 持续掉血 / 吸力 / 攻速 / 小地图。
   世界 Boss 的 `WBDOM` 已经有实现（`src/worldboss.js` 的 `domainTick`），
   先照它抄一遍，别新起一套。

## 卡点 / 已知短板

- **移动中的判定表达不了**：只有六种静态形状。"扫到一半停下""墙慢慢推过来"
  只能把整段会挨到的范围一次画出来。要等 `zone` 支持带时间的扫掠形状。
- **实体在暗场里只能是"亮团"**：狼群 / 鹿群 现在像发光水母，读的是排布不是形。
  要有形得给 `entity` 低模（三角楔子 + 眼睛），属于建模层。
- **活物没有厚度**：trail 是贴地 ribbon、弧带是竖直单面片。给 trail 加截面
  （三角 / 四边形）是另一个量级的活。
- 特效台**暂不发预览站**（用户 2026-10-27 口径：本地验证即可）。
  要给人看只能本地开 `file://` 或截图（`dev/probe-playground.js --shots all`）。
