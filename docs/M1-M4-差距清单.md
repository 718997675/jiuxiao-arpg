## M1 装备系统 2.0

### 1. 槽位 11 → 14（新增 披风 / 护符 / 命格）⚠️ 部分

实测 `SLOT_ORDER`（12 位）：

```
helm, chest, shoulders, gloves, boots, belt, amulet, ring1, ring2, weapon, offhand, relic
```

| 计划槽位 | 现状                                                  |
| ---- | --------------------------------------------------- |
| 护符   | ✅ 已有（`amulet`，木牌/玉坠/灵玉项链…）                          |
| 披风   | ❌ **没有装备槽**。`charforge.js` 里只有披风**外观几何**（跟装备无关的装饰件） |
| 命格   | ❌ **完全没有**（代码里搜不到任何 `命格`）                           |
| —    | ➕ 多出一个计划外的 `relic`（法器，30 件）                         |

**差距**：新增 2 个真实槽位 `cloak` / `fate`，并给它们各自 8 阶基底 + 词缀池。  
命格要按计划做成「只出稀有机制型词缀」（如「击杀后 3 秒攻速 +30%」）。

### 2. 基底 8 阶（凡兵 → 精铁 → 玄铁 → 地煞 → 天罡 → 仙品 → 神兵 → 太初）❌ 缺

实测只有 **5 阶**：

| 表               | 槽/线 | 阶数    | 件数              |
| --------------- | --- | ----- | --------------- |
| `ARMOR_BASES`   | 8 槽 | **5** | 8 × 5 × 3 = 120 |
| `WEAPON_BASES`  | 3 线 | **5** | 3 × 5 × 3 = 45  |
| `OFFHAND_BASES` | 3 线 | **5** | 3 × 5 × 3 = 45  |
| 合计              |     |       | **210 件**       |

件数 210 恰好等于计划值，但**结构不对**：计划是「每槽 8 件（一阶一件）」，现状是「每槽 5 阶 × 3 变体」。  
缺 **地煞 / 天罡 / 仙品** 三个中高段位，导致 40–60 级区间掉落几乎没有"换一层皮"的期待感。

**差距**：补 3 阶 × (8 槽 + 3 武器线 + 3 副手线 + 2 新槽) × 3 变体 ≈ **144 件新基底**。

### 3. ilvl 物品等级 + 词缀随 ilvl 缩放 ✅ 完成

`rollItem(ilvl)`、`affixValueCap(def, ilvl)`、`affixLevelBonus(ilvl)` 全链路已接；  
怪物掉落按 `e.level` 生成 ilvl（Boss +2）。

### 4. 词缀 24 → 64 ⚠️ 部分（数量达标，缺 4 个族）

实测 `AFFIXES` = **64 条**，且 64 条全部在 `STATS` 里有定义（不会出现"面板摆设"）。  
按 tier 分布：tier1 15 条 / tier2 32 条 / tier3 17 条。

计划要求的 7 个族对照：

| 族                      | 状态      | 说明                                                                                                 |
| ---------------------- | ------- | -------------------------------------------------------------------------------------------------- |
| 元素伤害 火/冰/雷/毒（各 3 阶）    | ❌ **缺** | 词缀表里没有任何 `fireDmg` / `iceDmg` / `lightningDmg` / `poisonDmg`。只有抗性（`fireRes` 等）和触发率（`burnChance` 等） |
| 单项抗性 + 全抗              | ✅       | `physRes / fireRes / iceRes / poisonRes / allRes`                                                  |
| **+N 技能等级**            | ❌ **缺** | 无 `skillLv` 类词缀。技能与装备**没有联动**，这是计划里明确点名的一条                                                         |
| 光环类（周围敌人减速/持续伤害）       | ❌ **缺** | 无 `aura*` 词缀，也无光环结算逻辑                                                                              |
| 资源类（上限/回复/消耗降低）        | ✅       | `mp / mpPct / mpReg / costReduce`                                                                  |
| 生存类（护盾/闪避/反伤/**濒死免疫**） | ⚠️      | 护盾 `shieldBonus`、闪避 `dodge`、反伤 `thorns` 有；**濒死免疫（冷却 60s）没有**                                       |
| 掉落类（拾取范围/经验/稀有度权重）     | ✅       | `pickupRadius / expGain / magicFind / dropRate`                                                    |

**差距**：补 12 条元素伤害词缀（4 元素 × 3 阶）+ 3 条 `+N 技能等级` + 2~3 条光环词缀 + 1 条濒死免疫 = **约 18 条**。

### 5. 符文之语（24 符文 + 12 之语，1–4 孔）✅ 完成

`RUNES` = 24，`RUNE_WORDS` = 12，全部带 `flag` 真机制：  
雷霆之语（普攻 18% 连锁天雷）、炎狱之语（击杀火焰爆炸）、玄冰之语（受击冰环冻结）、回响之语（15% 不进冷却）、血怒之语、护法之语…  
孔数与序列长度、顺序校验也做了。

### 6. 套装 5 → 12（每职业 3 + 通用 3）⚠️ 部分

实测 `SETS` = **9 套**，每职业 3 套（3~5 件）：

```
warrior: 龙骧(5) 磐石(4) 血怒(3)
mage:    星阙(5) 雷殛(4) 玄冰(3)
taoist:  青符(5) 丹鼎(4) 天师(3)
```

- ✅ 每职业 3 套：达成
- ✅ 效果已从纯数值升级为改机制（「烈焰突刺伤害 +80%」「暴击叠狂怒，每层伤害 +5%/攻速 +4%，最多 5 层」）
- ❌ **通用 3 套缺失**（`SET_TYPES` 只有 warrior/mage/taoist 三类，没有 universal）

**差距**：新增 3 套通用套（跨职业可用），并接进 `SET_TYPES` 与洗练/掉落池。

### 7. 洗练台（玄晶重 roll 单条）+ 装备升阶 ⚠️ 部分

### 4. AI 行为升级（包夹 / 远程风筝 / 自爆冲锋 / 治疗友军 / 召唤小怪 / 逃跑回血）❌ 缺

实测 `updateEnemies` 里普怪只有两条分支：

```
远程：远了走近，近了后退，刚好在射程内就射     ← 只有这个是「风筝」的雏形
近战：追到攻击距离 → 0.34s 前摇 → 判定伤害
```

- ❌ 包夹（两只怪分左右切入）—— 没有，只有"互相推开"的分离力
- ⚠️ 远程风筝 —— 有保持距离，但不会绕圈/拉扯，玩家一逼近就直线后退
- ❌ 自爆冲锋 —— **数据里 `charge: true` 写在 6 只怪身上，`game.js` 完全没读这个字段**（死字段）
- ❌ 治疗友军 —— 没有
- ❌ 召唤小怪 —— 只有精英词缀 `summoner` 会召，普通怪不会
- ❌ 逃跑回血（血量 <15% 且智力型）—— 没有

**差距**：这是一整块新系统（怪物 AI 状态机），不是补几行。

### 5. 世界 Boss + 限时事件 ❌ 全缺

- ❌ 每 30 分钟刷一只野外 Boss + 广播
- ❌ 天气事件（血月：怪物 +30% 攻击、掉落 +50%）
- 代码里搜 `worldBoss` / `weather` / `血月`（除地名「血月沼泽」外）零命中

### 6. 抗性系统 ✅ 完成（S5）

6 族群 × 5 元素抗性，`damageEnemy` 里按 `elem` 结算（正数减伤 / 负数增伤，夹在 -60~85），元素免疫词缀会覆盖。
