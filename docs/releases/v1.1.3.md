# v1.1.3 · 定向洗炼

发布日期：2026-10-23

## 指定词条一键自动洗

洗练原本是纯随机重 roll，想要某条特定词条可能要手动点上百次。这一版把这段重复劳动自动化。

- 洗练页每条词缀旁新增「定向」按钮，弹出候选词条面板。
- 候选池自动排除「其他词缀位已占用」的词条——同一件装备不会出重复词条，列出来也洗不出。
- 选中目标后显示预计次数与总花费，点「开始定向洗炼」自动消耗玄晶反复洗这一条，直到出现指定词条立即停止。
- 玄晶不足自动中断，已洗的次数与花费不浪费，词条停在中断时的状态。
- 已有目标词条、其他位占用同一词条，两种情形直接拒绝并提示原因。
- 单次洗练按钮与行为完全不变。

## 实现

- `items.js`：`reforgeTargets`（候选池）、`estimateTargetedReforge`（概率 → 期望次数 → 递增总价预估）。
- `game.js`：`targetedReforge`，安全阀 500 次；费用沿用每洗一次 +35% 的递增规则。
- `data-items.js`：`AFFIX_TIER_COLOR` / `AFFIX_TIER_NAME` 词条池档位配色。

## 验证

- `dev/probe-targeted-reforge.js` 15/15：候选排除、自动洗出即停、费用递增、材料中断、两类拒绝、单次洗练兼容、存档往返、UI 全流程。
