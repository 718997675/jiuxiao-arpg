# v1.1.9 · 套装体系重做为三套职业套装

发布日期：2026-10-24

## 设计动机

v1.1.2–S2 阶段的 12 套套装（每职业 3 套 + 通用 3 套）是「数值套装」：效果以加成为主，机制类 flag（雷击 / 火海 / 血怒 / 冰环 / 回响）散落各处，彼此没有区分度，也看不出「为这个职业设计」的意图。

本版把套装收敛为 **3 套，一职业一套**，每套 6 件（5 防具 + 套装武器），2/4/6 件三档激活，效果、词条、机制全部贴合职业特性：

| 套装 | 职业 | 定位 | 核心机制 |
| --- | --- | --- | --- |
| **龙骧** | 战士 | 突进冲撞 | 烈焰突刺伤害 / 突进距离；突进命中 3 人立刻刷冷 |
| **星阙** | 法师 | 法术范围 | 火球 / 冰霜新星 / 炎爆范围放大；陨星 +8 颗、冰霜新星冻结 |
| **青符** | 道士 | 持续召唤 | 毒雾范围与持续；灵狼继承 60%→90%、万剑归宗 +6 道 |

## 三档效果

每套统一 2 件（属性）/ 4 件（技能修正 + 机制）/ 6 件（质变）结构：

- **龙骧**：2 件攻击 +18% / 近战 +12% → 4 件烈焰突刺 +80%、旋风斩 +40%、突进距离 +30% → 6 件突进命中 3 人刷冷、剑神降世 +50%
- **星阙**：2 件技能伤 +18% / 范围伤 +15% → 4 件火球 / 冰霜新星 / 炎爆范围 +30%、消耗 -12% → 6 件陨星 +8 颗、冰霜新星冻结 1.2 秒
- **青符**：2 件召唤伤 +35% / 持续伤 +20% → 4 件毒雾范围 +30%、持续 +3 秒、回春 +30% → 6 件灵狼继承 60%→90%、万剑归宗 +6 道

## 套装技能修正通道

套装效果新增 `skillMods` 载体，与传世装备的 `uniqueSkill` 走同一条通道（`dmg / cd / cost / radius / count / dur` 六个键），`aggregate` 汇总后由 `castSkill` 消费。套装从此可以直接改机制，不再只是加数值。

## 套装件保底职业标志词条

新增 `SET_SIG` 表：套装件生成时，保证至少滚出 1 条本职业标志词条（战士：力量 / 近战 / 攻速 / 暴伤 / 击退；法师：技能伤 / 范围 / 冷却 / 暴击；道士：召唤 / 持续 / 回复）。用「预留」机制实现——先挑一条合法 key 进占用表，固定词条抢不走，第 1 条可洗词条定向生成，条数与其它规则完全不变。

## 旧档迁移

`normalizeItem` 会把已退出目录的 `setId`（青龙 / 朱雀 / 玄武 / 九幽 / 天罡 / 赤霄 / 九黎 / 玄冰 / 天雷 / 青木 / 紫府 / 山海）**剥离并降为玄品**：词条、孔位、已镶符文、强化次数全部保留，装备本身不销毁，玩家资产无损。

## 技术改动

- `src/data/data-items.js`：`SETS` 重写为 3 套职业套装；新增 `SET_SIG` 职业标志词条表
- `src/items.js`：`aggregate` 新增套装 `skillMods` 汇总；`makeAffix` 新增 `keyForce` 定向生成参数；`rollItem` 套装件标志词条保底；`craftSetItem` / `setCraftTargets` 按职业锁定；`normalizeItem` 旧套装迁移
- `src/game.js`：`longDash`（突进距离 +30%）、`chargeReset`（突进命中刷冷）、`novaFreeze`（冰霜新星冻结）、`starfall` 陨星 count 修正、`poison` 范围 / 持续修正、`wolfPrime`（灵狼继承 90%）、`thrust` / `avatar` / `heal` / `swordrain` 吃 `spow` 修正
- `dev/probe-set-system.js`（新增）：60 项，覆盖目录结构、三档激活、标志词条保底、掉落分流、打造锁定、旧档迁移、提示框
- `dev/test-s2.js`：套装断言 12 → 3，flag 白名单更新
