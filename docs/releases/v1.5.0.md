# v1.5.0 · 行囊重排：左装备栏 · 右行囊

> 2026-10-24　·　主题：布局分治与信息补位

## 一句话

行囊面板从「一张左右混排的长表」改成明确的两列：**左列是装备栏**（纸娃娃 + 常驻角色属性），**右列是行囊与各栏位**（格子 + 概览卡）。任何一列都不再留大片空白。

## 一、左列 = 装备栏

- 标题从「纸 娃 娃」改为「**装 备 栏**」——它现在装的不只是人形，还有整份人物面板。
- 纸娃娃下方新增**常驻的角色属性区**：根基 / 攻伐 / 守御 / 续航 / 机能五组，与属性面板（`C`）同源（共用 `statGroups()`），不会两处口径不一致。
- 属性条数随等级与装备增长，**超出左列可用高度就在列内滚动**（`overflow-y:auto` + `grid-auto-rows:min-content`）；切到材料 / 丹药 / 任务物品栏时照旧显示，不跟着收起。
- 两列排布（左列只有 300px，三列会把「暴击伤害 128%」挤断行）。

## 二、右列 = 行囊与各栏位

- 容量与排序条、四栏页签、提示行、格子（或材料 / 丹药 / 任务列表）都在右列。
- 提示行跟着栏位换口径：装备栏写「左键装备 · Shift+左键出售」，材料栏写玄晶用途，丹药栏写「点一行即服用」，任务物品栏写凭证来源。
- 底部新增**行囊概览卡**，把格子没占完的高度吃掉：
  - 容量进度条 + `已用 / 容量`
  - 所持品质分布（凡品 / 灵品 / 玄品 / 神兵 / 套装 / 传世，各带本品质配色）
  - 套装之力：逐套列 `已集 / 总件数` 与已激活档位；没有成套时给出获取提示
  - 两列操作小贴士

## 三、格子数 = 容量

之前未扩容只铺 16 格（两行），右列下半截是空的。现在**格子数直接等于容量**：40 格就是 5 行、104 格就是 13 行。好处有两个——扩容的收益是一排看得见的新空位；界面不会出现「有容量但看不见格子」的落差。

## 四、触屏（v1.5.0 补）

- 触屏不再单独写三列落位，**沿用桌面同一套 6 列 `grid-template-areas`**，只把宽度等比缩小。于是手机上的兵器与副手也是**底部一左一右各占三列**，而不是上下两条通栏。
- 触屏去掉「两列各自滚」：屏幕矮，固定面板高度会把一边压成一条缝。改成**整面板滚动**，装备栏与行囊都完整展开。
- 修正一条旧规则：`body.touch .inv-stats{display:none}` 会让手机上的属性区整块消失，已移除。
