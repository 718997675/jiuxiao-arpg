# v1.1.1 · 打孔

发布日期：2026-10-23

## 消耗玄晶为装备开孔

自然掉落按稀有度滚孔位，脸黑就拿不到符文之语。现在可以花钱补。

- 炼器台符文页新增打孔按钮，0 孔装备也能从第 1 孔打起。
- 第 1→5 孔分别 14 / 20 / 28 / 38 / 50 玄晶，越往后越贵。
- 戒指与项链不可打孔（与自然掉落规则一致，避免首饰位被符文之语垄断）。
- 符文页的装备列表纳入 0 孔装备，否则刚掉的白板根本点不进来。

## 实现

- `items.js`：`drillCost` / `canDrill` / `drillSocket`。
- `normalizeItem` 的孔位上限 4 → 5——不然打出的第 5 孔会在下次读档时被存档整形砍掉。

## 验证

- `dev/probe-drill.js` 10/10：逐孔扣费、孔数上限、首饰拒绝、`runes` 数组同步、新孔可镶嵌、存档往返、UI 渲染。
