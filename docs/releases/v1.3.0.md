# v1.3.0 · 行囊四栏 · 兵器握持 · 法器三十件

发布日期：2026-10-24

这一版把「装备界面」整体重做了：纸娃娃按身体朝向落位（参考暗黑 3）、行囊拆成四栏、兵器分单手 / 双持 / 双手，并新增第 12 个装备位——**法器**，三职业各 10 件共 30 件，每件都有独立介绍、来历、属性与术法联动，且都有自己的**器物图标**。

## 一、行囊四栏

| 栏位 | 内容 | 交互 |
| --- | --- | --- |
| **装备** | 纸娃娃 + 8 列行囊格 + 一键分解 / 排序 / 图鉴 | 左键穿戴 / 卸下，Shift + 左键出售 |
| **材料** | 玄晶四阶（白 / 青 / 紫 / 金）+ 手里已有的符文 | 只读清单，带存量与用途说明 |
| **丹药** | 回春丹 / 凝露 / 传送阵石 | **点一下就用**，数量实时同步 |
| **任务物品** | 按已完成委托生成凭证 | 不占行囊格位，栏头按「枚」计数 |

装备栏下方常驻**人物详细属性**（基础 / 攻伐 / 守御 / 续航 / 机能五组，最多 17 条），与属性面板 `C` 同源。

## 二、纸娃娃按身体朝向重排

六列网格 + `grid-template-areas` 写死落位，不依赖 DOM 顺序：

```
·      ·     头盔   头盔   ·      ·
护肩   护肩   战甲   战甲   法器   法器
护手   护手   战甲   战甲   项链   项链
戒指   戒指   腰带   腰带   戒指   戒指
·      ·     战靴   战靴   ·      ·
武器   武器   武器   副手   副手   副手
```

- 头在中上、**护肩左上 / 法器右上**左右对称，战甲居中占两行（躯干），战靴在下。
- 最底一条是**武器 / 副手两枚长格**，一左一右，横向显示「图标 + 名号 + 握持 · DPS」。
- 格子尺寸跟随部位：特大（战甲 / 兵器）/ 大（头盔 / 护肩 / 战靴 / 法器）/ 中（护手 / 腰带 / 副手）/ 小（项链 / 戒指）。
- 触屏另有 3 列版落位，武器与副手各占一条通栏。

## 三、单手 / 双持 / 双手

每个武器档位（3 职业 × 5 档）都恰好一件单手、一件双持、一件双手，由同档三变体的单次均伤派生：**最轻的 = 双持、居中 = 单手、最重 = 双手**（`WEAPON_HANDS`）。

| 握持 | 规则 |
| --- | --- |
| **单手** | 副手可配盾 / 珠 / 符 |
| **双持** | 主副手各持一把；主手已满时点行囊里的双持武器会直接补到副手 |
| **双手** | 占用副手位；装上时自动把副手卸回行囊，之后副手格锁定并拒绝穿戴 |

- 主手卸下时，副手那把双持兵器一并收回行囊。
- 异常存档（双手 + 副手并存）由 `repairHands()` 在 `recalc()` 前自动纠正。
- 提示框标握持标签：单手（灰）/ 双持（蓝）/ 双手（橙，明写「占用副手位」）。

## 四、法器 · 三十件

第 12 个装备位，戴在纸娃娃**右上角**。三职业各 10 件，**不做随机词条**（`fixed` / `affixes` 恒为空，永远不会被洗练或强化），属性与术法修正全部写在目录里。

| 职业 | 十件 |
| --- | --- |
| 战士 | 破军令 · 玄铁重盾 · 裂云战鼓 · 龙纹刀匣 · 虎符 · 血玉髓 · 断罪尺 · 万刃剑匣 · 镇岳碑 · 剑神幡 |
| 法师 | 星砂壶 · 冰魄瓶 · 雷纹印 · 焚天羽 · 寒玉镜 · 火枣核 · 玄冰鉴 · 天火罗盘 · 雷云幡 · 天罚朱笔 |
| 道士 | 桃符匣 · 兽骨铃 · 青囊卷 · 蚀骨瓶 · 符箭袋 · 太极盘 · 白虎牙 · 万剑匣 · 天师印 · 青龙鳞 |

- **每件都有**：`intro`（一句介绍）、`lore`（一段来历，30 段互不重复）、`stats`（固定属性，真实进面板）、`skill`（对某门术法的修正，走 `skillMods` 通道）。
- **30 件覆盖 30 门不同术法**，与 36 术法 × 108 变体一一咬合；修正只用 `dmg / cd / cost / radius / count / dur` 六个键。
- **附带术法** 4 件：剑神幡（剑神降世）、天罚朱笔（天罚）、天师印（天师符）、青龙鳞（青龙）。**未领悟也能施放，卸下立即失效**（`relicGrants()` 在 `castSkill` 的解锁判定里放行）。
- 掉落：完全随机掉落里占 **6%**；指定部位或指定品质的调用不会被顶掉；只出本职业（`relicPool(cls, ilvl)`，`ilvl ≤ cap + 6`，过滤空了回落到本职业全池）。
- 售价走 `itemValue()`，可正常卖出 / 分解。

### 器物图标

30 件各有一枚手绘 SVG 器物图形（`src/data/data-relic-icons.js`），统一 32×32、纯 fill 绘制：

- **外圈法阵**：双环 + 四方芒刺（`RELIC_AURA`），成组感；内圈是器物本体。
- **金色剪影 + 暗色开凿**：内部结构用 `#0b0a07` 直接挖掉，而不是叠半透明同色——32px 下才有真正的层次。
- 在纸娃娃法器位上**缓慢呼吸发光**（`relicBreath` 3.6s），行囊里比普通装备大一号，一眼能从刀甲堆里认出来。
