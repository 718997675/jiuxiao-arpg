# v1.2.1 · 天赋按级解锁 + 技能条 5 格手动配置

发布日期：2026-10-24

## 设计动机

v1.2.0 把天赋和术法铺到了 120 节点 / 36 技能，但两处节奏不对：

1. **天赋一开局就全开**——1 级角色能一眼看到 26 级的大节点，点不了也不知道差在哪，成长感被摊平了；
2. **技能栏是自动铺 8 格 + 翻页**——12 个技能里玩家想用的就那几个，翻页反而在打架时多一步，而且「换 build」在动作条上完全看不出来。

本版把两件事都收回到玩家手里：**天赋跟着等级一层层开**，**技能条 5 格自己摆**。

## 一、天赋随等级解锁

和技能同一套节奏：不到等级，节点在轮盘上直接标红「需 X 级」，点了只提示，不扣点。

| 层级 | 解锁等级 | 说明 |
| --- | --- | --- |
| 第 1 层（根） | 1 级 | `s1` |
| 第 2 层 | 4 级 | `s2` / `s3` |
| 第 3 层 | 8 级 | `s4` / `s5` |
| 第 4 层 | 12 级 | `s6` / `s7` |
| 中节点 | 18 级 | `m1` / `m2` |
| 大节点 | 26 级 | `L`（仍需本系已投 5 点） |
| 通用系 | 按链上序号 | 第 1 个 1 级 → 第 30 个 30 级 |

- 数据层：`data-talents.js` 新增 `NODE_UNLOCK` 表；职业系按 id 后缀（`s1` / `m2` / `L`）取解锁等级，通用系节点自带 `unlock`（链上序号）。`TALENT_NODES[id].unlock` 成为唯一读数口。
- 校验层：`canAllocTalent` 增加等级判断；UI 的 toast / tooltip / 轮盘节点文字三处都改为按解锁等级优先提示。
- **预设不再绕过等级**：`loadTalentPreset` 会跳过未解锁节点，顺带补了「单节点等级不得超过上限」的保护——低等级角色读高等级预设不会凭空吃到深层天赋。
- 升级时的日志会额外提示「天赋解锁 N 个新节点」，不用自己翻面板找。

## 二、技能条：5 格，手动配置

- **`SKILL_BAR_SIZE = 8`（两页）→ `SKILL_BAR_SLOTS = 5`（单条）**，翻页按钮与 `UI.skillPage` 一并删除。
- **怎么放上去**：术法面板（`K`）详情卡底部新增「技能条 1-5」按钮，点数字把当前选中术法放到该格；已在条上的技能会在网格左上角显示金色格号。已经在这格则按钮高亮；换到别格时原格自动腾空（换位，不复制）。
- **键位**：`1`-`5` 依次施放条上技能，右键 = 第 1 格；空位按键不施放任何技能（不会误触）。药水仍是 `Z` / `X`，传送石 `9`。
- **空位可点**：动作条空位是虚线「＋」占位，点一下直接打开术法面板；手机上 3×2 宫格前 5 格同样跟随技能条，空位点开面板。
- **自动填充只发生一次**：新角色 / 旧档没有整条配置时，按「已领悟 + 解锁顺序」补满 5 格；玩家手动腾空的格不会被偷偷填回去。
- **存档**：`skillbar`（长度恒为 5 的数组，空位 `null`）进 `pack / unpack / normalizeDoc`；逐格校验，非法 / 重复 / 非本职业的格子置空，**位置不动**（先前的写法用 filter 清洗会把空位挤掉，导致技能总被塞回第 1 格，本版一并修掉）。

## 三、顺手修掉的两个问题

- **技能等级与变体没有进存档**：`skills` 之前既不在 `pack` 也不在 `unpack`，重开就退回 1 级 / 变体 Ⅰ。本版补进三个存档函数。
- **`dev/test-save.js` 长期跑不起来**：文件清单漏了 `src/data/data-uniques.js`，`src/items.js` 里 `UNIQUE_BY_ID` 直接 `UNIQUE_ITEMS is not defined`。补上后 77/77 全绿。
