# v1.0.9 · 传世装备

发布日期：2026-10-23

## 新内容

- 新增「传世」品阶：金色掉落，独立 1.7 倍属性倍率，0 条随机词缀，靠固定词条、传世特性与技能强化取胜。

- 传世专属掉落：Boss / 精英怪提高传世掉率，40 级各职业各部位均有完整掉落池。
