# v1.2.2 · 九套职业套装

发布日期：2026-10-24

从「一职业一套 6 件」改成 **3 类型 × 3 职业 = 9 套**，每套件数 5 / 4 / 3，效果全部对着当前 36 术法 × 108 变体与 120 天赋节点设计。

## 一、设计骨架

| 职业 | 5 件 · 主套（防具 5） | 4 件 · 兵装套（武器/副手/腰带/项链） | 3 件 · 随身套（护手/腰带/项链） |
| --- | --- | --- | --- |
| 战士 | **龙骧**·突进 | **磐石**·守护 | **血怒**·暴击 |
| 法师 | **星阙**·烈焰 | **雷殛**·雷霆 | **玄冰**·冰控 |
| 道士 | **青符**·召唤 | **丹鼎**·毒煞 | **天师**·符箓 |

部位是刻意错开的，于是有两条成型路线：

- **9 格满配**：主套 5 + 兵装套 4 = 9 格全占，两套核心档同时点亮（毕业线）。
- **三套混搭**：随身套 3 + 主套 4 + 兵装套 2 = 9 格，三套低档叠加（过渡 / 换取向）。

## 二、九个套装与它们的 BD

**战士**

- **龙骧 5 件**：2 件攻击 +18% / 近战 +12%；3 件烈焰突刺 +80%、跃击 +30%、突进距离 +30%；5 件冲撞命中 3 人立刻刷新突刺、剑神降世 +50%。
  BD：烈焰突刺（连环 / 穿透）+ 跃击 + 剑神降世 + 战意咆哮，天赋走破军。
- **磐石 4 件**：2 件护甲 +25% / 格挡 +10% / 减伤 +6%；4 件荆棘 +80，**格挡瞬间反击 150% 护甲伤害并击退，盾墙期间翻倍**（新机制 `riposteGuard`）。
  BD：盾墙 + 反击 + 剑阵，靠格挡把伤害打回去；天赋走守护。
- **血怒 3 件**：2 件暴击 +8% / 暴伤 +40%；3 件**暴击叠「狂怒」最多 5 层**（每层 +5% 伤害 / +4% 攻速，4 秒未暴击掉 1 层），斩杀对残血 +40%（新机制 `frenzyStack`）。
  BD：血怒 + 斩杀 + 旋风斩；天赋走狂战。

**法师**

- **星阙 5 件**：2 件技能伤 +18% / 范围伤 +15%；3 件火球 / 炎爆 / 火墙范围 +30%、消耗 -12%；5 件陨星 +8 颗、火球命中留下 3.5 秒火海。

  BD：雷弧链（多跳）+ 雷罚 + 雷云；天赋走雷霆。
- **玄冰 3 件**：2 件冻结 +8% / 技能伤 +12%；3 件**被减速或冻结的目标受伤 +25%**（新 flag `deepfreeze`），暴雪 +2 秒、冰霜新星范围 +25%。
  BD：冰霜新星 + 暴雪 + 冰锥，先控后打；天赋走寒冰。

**道士**

- **青符 5 件**：2 件召唤伤 +35% / 持续伤 +20%；3 件毒雾范围 +30% 持续 +3 秒、回春 +30%；5 件灵狼继承 90%、一次召 2 头、万剑 +6 道。
  BD：灵狼 + 白虎 + 青龙 + 万剑归宗；天赋走召唤。

  BD：蚀骨毒雾 + 天师符 + 太极玄阵；天赋走丹道。
- **天师 3 件**：2 件技能伤 +20% / 暴伤 +30%；3 件五雷符 +40%、符箭 +2 张并穿透，**对中毒 / 燃烧 / 蚀骨目标伤害 +40%**（新 flag `runeburn`）。
  BD：五雷符 + 符箭 + 万剑，用毒雾 / 燃烧打底再爆；天赋走符箓。

## 三、词条与载体

- 每个套装带 `set.sig`：**逐套的词条取向**（龙骧偏攻击 / 移速、磐石偏防御 / 格挡、玄冰偏冻结 / 减速…），套装件保底一条本套标志词条。部位词条池禁掉的取向（武器不出防御、首饰不出近战）会自动回落到本职业取向。
- 档位效果仍走 `stats / skillMods / flag / special` 四种载体，新增 `specials` 数组支持「一档点亮多个机制」（青符 5 件：灵狼质变 + 双狼同开）。
- 毒雾现在会给命中目标留 2.5 秒「蚀骨」印记（`venomT`），作为天师套增伤的判定依据；毒雾本身伤害未改。

## 四、界面与迁移

- 套装图鉴按职业分组，卡片显示「类型标签 + 件数套 + 已集 / 总数」，加成档位按当前件数点亮。
- 提示框标题改为「套装名·类型（n/总）」，件数截断显示（旧档 6 件不会出现 6/5）。
- 旧档迁移：6 件套时代的**套装武器**已不在新目录内，读档时剥离套装标识降为玄品，词条 / 孔位 / 符文全部保留；仍在目录内的防具部件不受影响。
