# v1.1.0 · 指哪打哪

发布日期：2026-10-23

## 技能瞄准与判定范围

- 每个技能新增 `cast`（自身 / 方向 / 地面 / 索敌）与 `castRange` 施法距离。
- 「裂地震击」「冰霜新星」从固定自身范围改为指定地面落点，落点自动夹在施法距离内。
- 「炎爆术」「陨星天火」「蚀骨毒雾」「万剑归宗」统一按施法距离限制落点，不再能跨屏释放。
- 「烈焰突刺」「火球术」按鼠标 / 触屏朝向释放；「雷弧链」「五雷符」优先锁定落点附近敌人，超出施法距离时回退到最近敌人。
- 施法瞬间在地面显示方向线与落点圈；技能栏 tooltip 标注「自身 / 指定位置 / 指定方向 / 自动索敌」和施法距离。
- 触屏端继续使用自动瞄准：优先最近敌人，没有敌人时朝摇杆方向取 8 码落点。

## 减少技能冷却的词条

- 「冷却缩减」随机词条从稀有池（tier 3）下放到强化池（tier 2），数值 3% ~ 8%，并提高出现权重。
- 保留「固定冷却缩减」稀有词条（1 ~ 2 秒），与百分比冷却缩减叠加。
- 词条仍受 45% 冷却缩减上限约束，技能冷却不低于 0.5 秒。

## 增益 / 减益栏

- 技能栏上方新增 buff 栏，显示当前增益、减益与护盾。
- 增益为金色边框，减益为红色虚线边框，显示图标、名称与剩余秒数，按剩余时间排序。
- 已接入：战意咆哮、血怒、太极玄阵、剑神降世、玄冰护盾、迟滞、中毒。
- 同名技能增益重复施放会刷新而不是叠层；不同来源的同类 buff 仍可独立存在。
- 触屏端 buff 栏跟随技能宫格定位，并随 HUD 缩放。

## 验证

- `node --check` 通过全部改动文件。
- Edge 无头浏览器冒烟：开局、地面技能落点夹取、裂地震击命中目标、buff / debuff 显示与清空、冷却缩减计算、触屏技能宫格与 buff 栏定位均正常。
