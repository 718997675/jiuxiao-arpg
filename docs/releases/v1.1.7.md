# v1.1.7 · 词条职业适配与传世定位

发布日期：2026-10-23

## 词条池按职业 + 部位差异化

此前 64 条词条是三职业共用一份池子，战士能洗出「灵力上限」，法师能洗出「力量」，武器能出「护甲」。本版把它拆开。

### 职业维度

| 职业 | 出什么 | 不出什么 |
| --- | --- | --- |
| 战士 | 力量、近战伤害、暴击、护甲、反伤、格挡、吸血 | 灵力、法术伤害、召唤、持续伤害、冷却缩减、护盾 |
| 法师 | 灵力、雷火范围、点燃 / 冰封、冷却、护盾、穿甲 | 力量、近战专精、格挡、吸血、召唤、持续伤害 |
| 道士 | 灵力、毒雾持续、召唤、自愈、技能伤害、投射物 | 力量、近战专精、格挡、纯爆发范围、护盾 |

掉落时按**掉落者的职业**生成词条，职业倾向记在新字段 `item.affixCls` 上。防具基底本身仍是通用的，跨职业穿戴规则不变——只是词条内容贴合生成时的职业定位。

### 部位维度

- **武器 / 副手**：不出纯防御（护甲、减伤、格挡、闪避、反伤、全系抗性）
- **六件防具**：不出武器专精（穿甲、暴击伤害、斩杀、先手、暴击后攻速、吸血）
- **项链 / 戒指**：只出稀有属性，不出大面积伤害（近战 / 投射 / 范围 / 持续 / 召唤）与防御

### 通用装备走中性池

基底不绑职业的装备（大部分防具、首饰）使用**三职业排除项的并集**，只出人人都能用的中性词条（生命、护甲、抗性、暴击、通用增伤）。否则通用胸甲掉出「力量」，法师穿着就是废词条。

### 实现方式

用**排除法**而不是白名单：新增词条默认对所有职业 / 部位开放，只有明确不合用的才登记进 `AFFIX_CLS_DENY` / `AFFIX_SLOT_DENY`。白名单漏登记会让新词条永远不出现，排除法漏登记只是宽松一点。

过滤后池子不足 10 条时自动放弃过滤，**任何时候都不会让某个「职业 × 部位」组合的池子枯竭**。

## 传世改为最终装备

- 品质色从暗金 `#d9a441` 改为**红色** `#ff3b3b`，背包格子描边、角色光效同步
- 明确为装备链终点：不在品质升级链内，无法继续提升品质；不带随机词条，强度来自固定属性、传世特性与技能强化
- 品质升级入口对传世与套装给出专门提示，不再落到笼统的「已是最高品质」

## 技术改动

- `src/data/data-items.js`：新增 `AFFIX_CLS_DENY` / `AFFIX_SLOT_GROUP` / `AFFIX_SLOT_DENY` / `AFFIX_UNIVERSAL_DENY` / `affixPool()` / `affixSlotGroup()`
- `src/items.js`：`makeAffix` / `makeFixedAffix` 增加 `cls`、`slot` 参数；掉落、洗练、强化、套装打造、品质升级五处的生成全部带上职业与部位；`rollItem` 写入 `affixCls`；`normalizeItem` 校验该字段
- `src/game.js`：品质升级补词条时带上职业与部位；`upgradeItemQuality` 对传世 / 套装给出明确拒绝文案
- `src/data/data-core.js`：`RARITY.unique.color` 改红，补最终装备注释
- `src/actors.js`、`index.html`：传世光效与格子描边同步改红

## 升级提示

- 旧存档里已有的词条**原样保留**，不会被强制洗掉；新掉落与新洗练按新规则走
- 旧装备没有 `affixCls`，涉及洗练时走中性池（不会突然冒出跨职业技能）
