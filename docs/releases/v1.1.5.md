# v1.1.5 · 古风角色与单条洗炼

发布日期：2026-10-23

## 古风三职业角色骨架

角色从「盒子人」换成程序化生成的古风低模，仍然零素材、零贴图、零模型文件。

- 新增 `src/charforge.js`：交领右衽、广袖、腰封玉扣、发髻束发、甲裙分片、披风、道冠全部用几何体现搭。
- 骨架层级与 `buildHumanoid` 完全对齐（`legL/legR@0.92`、`torso@0.92`、`headG`、`armL/armR` 挂 `torso@0.52`），动画 / 换装 / 武器 / AI 一行没改就复用了。
- 三职业各自配色：战士朱红墨铁赤金、法师靛青月白银、道士青碧米白黄铜。
- 自带动作曲线：屈膝、袖子与下摆摆动、呼吸；读取原有 `moving / atkAnim / atkType / flash / die` 状态，攻击按职业区分招式。
- 换装挂点（`helmG / shoulderL / shoulderR / capeG / weaponHand / offHand`）保持为空 Group，造型件单独放在 art 组——`clearGroup` 不会误删造型件，也不会重演「黑线」事故。
- 装备染色不再覆盖古风整体配色，装备外观只通过头盔 / 护肩 / 披风 / 武器体现。
- `game.js` 优先用 `CharForge`，任何异常自动退回 `buildHumanoid`。

实测：三职业各约 1600~1780 面，零控制台报错，攻击计时正常归零。

## 武器建模重做

原来 `buildWeapon` 全是 box 拼的平板，`sword` 刀身 1.55 米、`saber` 1.45 米，角色身高才 1.88 —— 武器比人还高，边缘全是直角。

- 新增 `src/weapons.js`（`CharForge` 与 `actors.js` 共用同一份建模）。
- 刀身用 `THREE.Shape` + `ExtrudeGeometry` 挤出真实轮廓：大刀是单边刃（刀背外鼓、刃口内收、刀尖斜收），剑是双刃菱形收尖。
- 尺寸收到人身的 60%：大刀总长 1.13 米（刀身 0.85 + 柄 0.28）、剑 1.02、桃木剑 0.96、法杖 1.42。
- 护手做出造型：大刀为椭圆盘，剑为十字护手带两端小球；柄部加缠绳环与柄头球，法杖加铜箍与云纹弯钩，盾改为圆盾带中央凸面。
- 刀身固定钢色，装备品质色转成辉光；`metalness` 压到 0.55 —— 场景没有环境贴图时，纯金属背光面会直接黑成剪影。

## 战士与道士的斜劈

原来只有 `armRx`（前后抬落）在动，刀尖全程走 `x≈0` 的竖直平面，观感就是「手上下动」。

- 新增 `armRy`（水平横扫）、`armRz`（外展内收）与 `sink`（屈膝沉身）通道；`update` 里三轴一起覆盖，否则只改 x 时 y/z 会残留待机姿态把挥击方向拖偏。
- 蓄力拧腰 +72°、手臂举到右肩后上方；挥出时腰反转 -45°，刀扫过正前落到左下。
- 新增 `WPN` 翻腕曲线：待机 -1.02 → 蓄力 -0.88 → 挥出 +0.16 → 触底 +0.10。刀在挥出瞬间翻下去，才有「劈」而不是「端」的观感。
- 道士换成同构三轴，按桃木剑特点区分：动作更短更快（蓄力段 0.38 到位）、翻腕幅度收窄、左手保留结印起手。
- 长武器待机改为斜持：1.34 米长刀垂直握持必然插进地面 0.5 米，改为 `-0.78` 并外侧偏转 0.55，刀身最低点 y=0.182。

实测：战士刀尖水平跨度 2.45 米 / 竖直 2.18 米（比值 0.91），道士 2.37 / 1.95（比值 0.81），都跨到了身体另一侧。

## 定向洗炼改为单条升级

定向洗炼从「洗出指定词条」改成**锁定单条词条的升级器**：每次只动 1 条，数值必定严格高于洗练前的数值，绝不下降。

- 词缀数值理论上限 `affixValueCap = round(max × (1 + ilvl×0.055) × 1.30)`，即品质拉满（q4）掷满。
- 同 key 重掷最多 240 次直到 `val > prev`；贴近分布尾部掷不出更高值时退化为 `min(cap, prev+1)` 保底；已封顶直接拒绝。
- 封顶后按钮变灰且**不再扣玄晶**，面板用进度条显示「当前值 / 本装备上限」。
- 原「洗出指定词条」流程没有删，收进面板里的「改为指定词条」入口。

## 开发与调试工具

- `dev/serve.mjs`：全响应 `Cache-Control: no-store` 的本地开发服务器。`python3 -m http.server` 不发缓存头，浏览器启发式缓存旧 `.js` 会伪装成「函数未定义」的假故障。
- `dev/atk-lab.html`：攻击动作调试台，拖进度条逐帧看姿态，把刀尖轨迹画成曲线并算出竖直 / 水平跨度比。
- `dev/probe-targeted-reforge.js`：定向洗炼回归探针（25 项）。
